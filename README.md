# 📊 Rohit Sul - Personal Portfolio Website

A clean, responsive, dark-themed personal portfolio website built with single-file HTML5, modern CSS3 (Variables, Grid, Flexbox, Animations), and Vanilla JavaScript.

Designed and tailored for **Data Analyst** roles to present key analytics projects, technical skills, work experience, and quick contact channels.

---

## ✨ Features

* **🎨 Modern Dark Theme UI**: Custom cyber/tech style layout with interactive gradient borders, animated SVG banners, and glowing UI elements.
* **⚡ Fully Responsive & Mobile-Friendly**: Smooth scroll navigation, collapsible mobile navbar, and adaptive layout adjustments across all screen sizes.
* **⌨️ Dynamic Typing Effect**: Real-time rotating dynamic role titles in the hero section.
* **📈 Animated SVG Banners**: Customized SVG header cards for showcase projects (Blinkit Analysis, Zepto Dark Store Analysis, and FaceLog).
* **🎯 Pure Vanilla Tech Stack**: Zero external JavaScript dependencies or heavy frameworks for fast load times.
